호출 관계는 정적 분석이 확정하고, AI는 설명만 합니다. 설명 속 호출 관계는 분석 결과와 대조해 검증됩니다.
  1. 1
    저장소를 고르고 구조 개요를 봅니다 왼쪽 그래프가 클래스·파일 단위 의존 관계입니다. 더블클릭하면 그 안의 함수들로, 함수를 다시 더블클릭하면 그 함수의 호출 흐름으로 들어갑니다. 클릭하면 코드가 아래에 열립니다. 🔒 저장소는 외부 전송과 추적이 차단됩니다.
  2. 2
    궁금한 곳을 묻습니다 자연어로 묻거나, 그래프에서 클래스를 눌러 함수를 고릅니다.
  3. 3
    진행 단계를 확인합니다 보안 게이트 → 시작 함수 → 호출 따라가기 → 설명 → 검증. 검증에 실패하면 "다시 설명"이 표시됩니다.
  4. 4
    구역을 구분해서 읽습니다 구조(검증됨)는 믿어도 되는 호출 관계, 확인 안 됨은 직접 확인할 부분, 해석은 AI의 서술로 검증되지 않았습니다.
  5. 5
    문서와 코드를 맞춰 봅니다 "기획서의 3단계에 해당하는 코드가 ○○ 맞아?"처럼 물으면 저장소 안 문서(md·txt)의 해당 절을 찾고, 문서에 적힌 호출 관계를 코드와 대조합니다. 문서 근거는 문서 내용일 뿐 검증 대상이 아니고, ✗ 불일치·코드에 없는 이름은 문서가 낡았을 수 있다는 신호입니다.
함수를 바꾸기 전에는 그래프의 "영향 범위"로 이 함수를 호출하는 곳을 확인하세요.
